## Contexto

Para esse projeto, os alunos receberam a tarefa de desenvolver uma nova página web para a empresa `Potenze Iluminação LED`, uma fabricante de luminárias industriais do Paraná.

Essa empresa já atua no setor há mais de uma década, e sua página web permaneceu a mesma desde sua criação. Essa página, por sua vez, tinha um visual extremamente datado, má funcionalidade e uma experiência de usuário ruim.

E assim, nossa equipe desenvolveu esse projeto, focado tanto em solucionar os problemas apresentados em sala quanto em ganhar experiência com as ferramentas mais utilizadas no mercado e em criação e entrega de projetos para clientes.

É um projeto mais voltado para o Front-End, sem a utilização de outros frameworks Back-End, como `Express.js`.

## Tech Stack

Para esse projeto, as seguintes ferramentas foram usadas:
- `React`: Biblioteca em Javascript/Typescript para modularização e estrutura do código;
- `Vite`: Ferramenta de construção e geração de estrutura (scaffolding) para o projeto;
- `Tailwind CSS`: Framework de CSS para auxiliar na estilização das páginas. Proporciona mais controle/liberdade para estlização que CSS convencional;
- `Netlify`: Plataforma escolhida para hospedagem do projeto;
