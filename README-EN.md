## Context

For this project, students were tasked with creating a new web page for `Potenze Iluminação LED`, an industrial luminaire manufacturer from the brazilian state of Paraná.

This company has been active for more than a decade, and its web page has remained the same since. As a result, this page has very dated looks, bad functionality and poor UX. 

Thus, our team got together to assemble this project, focusing on not only solving the problems presented in class, but also gaining experience with using industry-standard tools and with project creation and delivery for clients.

This is a more Front-End focused project, so it does not utilize Back-End frameworks, like `Express.js`.

## Tech Stack

For this project, the following tools were utilized:
- `React`: Javascript/Typescript library for code structure and modularization;
- `Vite`: Used for building, structure generation and scaffolding for the project;
- `Tailwind CSS`: CSS Framework for styling. It provides more control/freedom over styling than vanilla CSS;
- `Netlify`: Cloud service provider chosen to host this project;
